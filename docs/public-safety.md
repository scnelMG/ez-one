# 공개 안전성 검토

## 공개 기준

EZ-ONE은 웹 서비스와 Chrome Extension 기반 프로젝트입니다. 실제 `.env`, OAuth secret, API key, token, 개인 credential, 사용자 개인정보는 공개 대상에서 제외합니다.

## 검토 포인트

- 공개 자료: 요구사항, API 명세, 아키텍처, 테스트 계획, 최종 발표 자료
- 제외 자료: 실제 환경 변수, 운영 DB 정보, OAuth secret, 실제 사용자 데이터

## 리뷰어 안내

평가 대상은 채용 공고 저장, 자기소개서 준비 워크스페이스, 확장 프로그램 연동, 인증/권한 설계입니다.
