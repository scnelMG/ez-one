# EZ-ONE 발표 자료

이 디렉터리는 EZ-ONE 최종 발표 자료를 보관합니다.

| 파일 | 설명 | 크기 |
| --- | --- | ---: |
| `ez-one-final-presentation.pdf` | GitHub에서 바로 열어볼 수 있는 최종 발표 자료 | 약 18 MB |
| `ez-one-final-presentation.pptx` | 편집 가능한 원본 발표 파일 | 약 31 MB |

## 공개 기준

- 발표 자료는 포트폴리오 검토자가 프로젝트 문제 정의, 서비스 흐름, 주요 기능, 결과를 빠르게 확인할 수 있도록 포함했습니다.
- `.env`, token, OAuth secret, API key, 개인 credential은 포함하지 않습니다.
- 발표 자료에 포함된 팀/제출 맥락은 프로젝트 산출물 설명을 위한 범위로만 사용합니다.
