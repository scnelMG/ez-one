# 37. 최종 제출 보고서

작성일: 2026-06-25

## 제출 범위 요약

EZ-ONE은 취업 준비자가 채용 공고를 저장하고, 공고별 지원 준비 자료를 한곳에서 관리하며, 반복 입력하는 서류 정보를 재사용할 수 있도록 만든 취업 준비 워크스페이스입니다.

최종 제출물에는 백엔드 API, 프론트엔드 화면, Chrome Extension, 테스트 코드, 빌드 산출물이 포함됩니다. 문서에 남아 있는 P2/P3 요구사항은 전체 제품 백로그이며, 아래 구현 완료 범위에 포함된 항목만 제출 기준 기능으로 봅니다.

## 구현 완료 기능

| 영역 | 구현 내용 |
| --- | --- |
| 인증/계정 | 이메일 회원가입/로그인, Google OAuth 로그인, JWT 발급/재발급/로그아웃, 현재 사용자 조회/수정 |
| 온보딩/마이페이지 | 희망 직무, 기업 유형, 산업, 지역, 기술스택, SSAFY 여부 저장 및 수정, 내 계정/FAQ/약관 화면 |
| 메인 대시보드 | 지원 현황 요약, 상태 카드 이동, 작성 중 지원서, 취업 스터디 카드, 공고 장바구니 이동 |
| 공고함 | 직접 입력/확장 프로그램 저장 공고 목록, 검색, 정렬, 상태 필터, 상태 변경, 상세 화면, 삭제/보관 |
| 지원 워크스페이스 | 공고 기본 정보, 회사 정보, 자기소개서 문항/초안, 자동 저장, 버전 생성/비교 |
| 참고자료 | JD, 뉴스, DART, 인재상, 자유 메모 등 공고별 참고자료 생성/조회/수정/삭제 |
| 서류 입력 정보 | 기본 정보, 학력, 경력, 프로젝트, 자격증, 수상/교육, 커스텀 항목 관리 |
| Chrome Extension | Jasoseol.com 공고 추출, 미리보기, 직무 다중 선택, 공고 저장, 로그인/오류 안내 |
| Extension 서류 입력 보조 | 저장된 서류 입력 정보를 현재 지원 페이지 입력칸에 사용자 실행 방식으로 채움 |
| Notion 연동 | Notion OAuth 연결, `JOB_ONLY` 동기화 설정, 저장 공고 동기화, 동기화 로그 |
| 과거 지원 이력 | 지원 이력 목록, 기간/결과/기업 유형 필터, 요약 지표, 워크스페이스 연결 |
| 취업 스터디 | 스터디 생성/초대/참여, 자소서 공유, 피드백, 구성원 권한 검증 |
| 고객지원 API | 사용자 문의 등록/조회 API와 문의 유형 제한 |
| SSAFY 추천 공고 | Mattermost 수집 공고 목록, SSAFY 사용자 제한, 점수/마감/정렬 표시, 공고 저장 |
| DART 참고자료 보조 | OpenDART 공시 조회, GMS 기반 분석 보조, 사용자 확인 후 DART 참고자료 저장 |
| 기업 정보 보강 | 금융위원회 기업기본정보, OpenDART 기업개황, 내부 fallback을 통한 회사 정보 보강 |

## 제출 범위에서 제외한 기능

| 기능 | 제외 기준 |
| --- | --- |
| 독립 알림 채널 | 화면 내 상태 표시는 제공하지만 별도 알림 센터/푸시/메일 알림은 제공하지 않음 |
| 외부 캘린더 연동 | 마감일과 목록 정렬은 제공하지만 Google Calendar 등 외부 캘린더 연동은 제공하지 않음 |
| 관리자 운영 화면 | 관리자 전용 사용자/공고/기업 관리 화면은 제출 범위에서 제외 |
| 확장된 Notion 동기화 | 자소서/도화지/참고자료까지 Notion으로 동기화하지 않고 저장 공고 `JOB_ONLY`만 제공 |
| AI 자동 확정 | AI/DART/추천 보조 결과는 사용자가 확인해야 하며 자소서나 외부 지원서에 자동 반영하지 않음 |
| 실서비스 외부 크롤링 자동화 | 추천 후보 저장과 보강 API는 구현되어 있지만, 제출 패키지는 로컬 실행과 테스트 검증 기준 |

## 요구사항 문서 해석 기준

- `docs/04_requirements.md`는 Notion 요구사항 DB 전체를 보존한 구현용 사본입니다.
- P1/P2/P3가 모두 포함되어 있으므로, 그 문서에 있는 모든 행이 최종 제출 기능이라는 뜻은 아닙니다.
- 최종 제출 기준 구현 여부는 이 문서의 "구현 완료 기능", `docs/23_traceability.md`, `docs/33_mvp-qa-results.md`를 함께 봅니다.
- P2/P3 행 중 일부는 구현되어 있습니다. 이 경우에도 제출 설명에서는 "확장 구현"으로 구분하고, P1 핵심 흐름과 섞어 말하지 않습니다.

## 검증 한계

- Live Google OAuth와 live Notion provider 호출은 자동 테스트에서 실제 외부 계정으로 수행하지 않았습니다.
- 일부 live smoke 성격의 테스트는 환경 변수와 외부 API 상태에 의존하므로 기본 전체 테스트에서는 스킵됩니다.
- 제출 패키지에는 실제 `.env` 파일을 포함하지 않았고, 실행 환경에서는 각 모듈의 `.env.example`을 기준으로 값을 설정해야 합니다.
